# maps-scraper
A Python tool using Playwright to scrape Google Maps, find local businesses without a website, and export leads instantly to Excel.

<div align="center">
  <h1>🗺️ maps-scraper</h1>
  <p><b>A Python tool using Playwright to scrape Google Maps, find local businesses without a website, and export leads instantly to Excel.</b></p>
</div>

<hr>

<h2>✨ Features</h2>
<ul>
  <li><b>Deep Scraping:</b> Automatically scrolls through Google Maps search results.</li>
  <li><b>No-Website Filter:</b> Identifies local businesses that lack a digital footprint.</li>
  <li><b>Rich Contact Extraction:</b> Captures phone numbers, addresses, emails, and social media links.</li>
  <li><b>Crash-Proof Real-Time Export:</b> Saves data instantly to Excel as it finds them.</li>
</ul>

<hr>

<h2>🚀 Quick Start</h2>
<p>Install dependencies:</p>
<pre><code>pip install playwright openpyxl
playwright install</code></pre>

<p>Run the script:</p>
<pre><code>python3 scrapermaps.py</code></pre>
